# CommuniQ AI Server — Service Setup Guide

This guide walks you through setting up every external service the AI server depends on. Follow each section in order.

---

## Overview of Services

| Service | Purpose | Cost | Required |
|---|---|---|---|
| Groq API | LLM (Llama 3.1 8B) + STT (Whisper Large V3) | Free tier | Yes |
| edge-tts | Text-to-speech (Indian English voice) | Free, no account | No (auto-used) |
| ngrok | Expose local server to physical mobile devices | Free tier | No (dev only) |

---

## 1. Groq API — LLM + Speech-to-Text

Groq powers both the conversation AI (Llama 3.1 8B) and the speech transcription (Whisper Large V3). The free tier is generous enough for all development and prototype use.

### Step 1 — Create a Groq account

1. Go to [console.groq.com](https://console.groq.com)
2. Click **Sign Up** — you can use Google or GitHub
3. Complete email verification if prompted

### Step 2 — Generate an API key

1. After logging in, go to **API Keys** in the left sidebar
2. Click **Create API Key**
3. Give it a name (e.g. `communiq-dev`)
4. Copy the key — it starts with `gsk_`

> You will only see the full key once. Copy it immediately.

### Step 3 — Add to your .env file

Open `ai-server/.env` and set:

```
GROQ_API_KEY=gsk_your_key_here
```

### Step 4 — Verify it works

```bash
cd ai-server
venv\Scripts\activate        # Windows
python tests/test_groq.py
```

Expected output: a short response from the LLM printed to the terminal. If you see `GROQ_API_KEY is not set`, the `.env` file is not being found — make sure you are running from the `ai-server/` directory.

### Groq Free Tier Limits (as of 2026)

| Model | Requests/min | Tokens/min | Tokens/day |
|---|---|---|---|
| llama-3.1-8b-instant | 30 | 131,072 | 1,000,000 |
| whisper-large-v3 | 20 | — | 7,200 minutes/day |

This is more than sufficient for a development prototype.

## 2. edge-tts — Default Text-to-Speech

edge-tts is a free Python library that uses Microsoft Edge's TTS service. It requires no account, no API key, and no setup. It was already installed as part of `requirements.txt`.

**Voice used:** `en-IN-NeerjaNeural` — Indian English, female, natural neural voice.

### Verify it works

```bash
cd ai-server
venv\Scripts\activate
python -c "import asyncio; import edge_tts; print('edge-tts OK')"
```

### Other available Indian English voices

If you want to change the default voice, edit `app/tts.py` and change `DEFAULT_EDGE_VOICE`:

| Voice ID | Description |
|---|---|
| `en-IN-NeerjaNeural` | Female, Indian English (default) |
| `en-IN-PrabhatNeural` | Male, Indian English |
| `en-IN-AaravNeural` | Male, Indian English, slightly different accent |

To list all available voices:

```bash
python -c "import asyncio; import edge_tts; asyncio.run(edge_tts.list_voices())" | findstr "en-IN"
```

## 3. ngrok — Expose Server to Physical Devices

When you test the Flutter app on a real Android or iOS device, the device cannot reach `localhost` on your development machine. ngrok creates a public HTTPS URL that tunnels to your local server.

### Step 1 — Install ngrok

**Windows:**
1. Go to [ngrok.com/download](https://ngrok.com/download)
2. Download the Windows ZIP → extract `ngrok.exe` somewhere on your PATH
3. Or install via winget: `winget install ngrok`

**macOS:**
```bash
brew install ngrok
```

### Step 2 — Create a free ngrok account

1. Go to [dashboard.ngrok.com](https://dashboard.ngrok.com)
2. Sign up for free
3. Copy your **Authtoken** from the dashboard

### Step 3 — Add your authtoken

```bash
ngrok config add-authtoken YOUR_TOKEN_HERE
```

### Step 4 — Start a tunnel

With the AI server already running on port 8000:

```bash
ngrok http 8000
```

ngrok will display something like:

```
Forwarding   https://abc123xyz.ngrok-free.app -> http://localhost:8000
```

Copy the `https://...ngrok-free.app` URL and use it as the base URL in the Flutter app's API configuration.

### Important ngrok notes

- The URL changes every time you restart ngrok (free tier). You will need to update the Flutter app config each session.
- ngrok free tier allows 1 active tunnel and has some request limits, but is more than sufficient for development.
- Never expose sensitive keys or production data through ngrok.

---

## 4. Starting the Server

Once everything above is configured:

```bash
# Navigate to ai-server
cd ai-server

# Activate virtual environment
venv\Scripts\activate          # Windows
source venv/bin/activate       # macOS / Linux

# Start the server with hot reload
uvicorn app.main:app --reload --port 8000
```

The server will be available at `http://localhost:8000`.

Interactive API docs (auto-generated by FastAPI): `http://localhost:8000/docs`

---

## 5. Running the Test Pipeline

With the server running in one terminal, open another and run:

```bash
cd ai-server
venv\Scripts\activate
python tests/test_pipeline.py
```

This tests `/health`, `/tts`, and `/evaluate` automatically.

For the `/conversation` test, drop a short voice recording (any format: m4a, wav, webm) named `sample_audio.m4a` into the `ai-server/` folder and re-run. The test will transcribe it, generate an AI response, and save the audio output as `test_conversation_output.mp3`.

## 6. Troubleshooting

**`GROQ_API_KEY is not set` on server start**
- Make sure `ai-server/.env` exists (not just `.env.example`)
- Make sure you are running uvicorn from the `ai-server/` directory, not from a parent folder

**TTS produces silence or fails**
- By default edge-tts is used. If it fails, check your internet connection (edge-tts calls Microsoft's servers)
- If you have `GOOGLE_APPLICATION_CREDENTIALS` set and the path is wrong, TTS will fail. Either fix the path or clear the variable to fall back to edge-tts

**`Address already in use` on server start**
- Another process is using port 8000. Either stop it or change the port: `uvicorn app.main:app --port 8001`
- On Windows, find and kill the process: `netstat -ano | findstr :8000` then `taskkill /PID <pid> /F`

**ngrok URL not reachable from Flutter**
- Make sure the server is running before starting ngrok
- Use the `https://` URL, not the `http://` one
- If you restarted ngrok, update the URL in the Flutter app config — it changes every time on the free tier
